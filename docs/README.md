# docs/

Current, durable reference for mcp-tui that is not part of the website:

- `SUBMIT.md`: the community catalogs mcp-tui is listed in, with the canonical metadata and blurbs.
- `adr/`: full decision records promoted from a `DECISION:` line in `.claude/rules/architecture.md`.

The website (Astro Starlight, deployed to dev.standardbeagle.com/mcp-tui) and the demo
recording toolchain that feeds it are in `site/`. Plans and specs are not kept here: track
in-flight work in worktrack, and commit a plan a task cites under `docs/plans/` only while
that task is open, removing it once the work lands.
