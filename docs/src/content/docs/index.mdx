```bash

mcp-tui --url http://localhost:8080/mcp                 # TUI
mcp-tui --url http://localhost:8080/mcp tool list       # CLI
```

## From a manual check to CI

Every TUI action has a CLI equivalent: `c` copies one call, `Ctrl+E` exports
the session as a replay script. The CLI prints JSON for `jq` and exits
non-zero on failures you choose.

<DemoVideo name="cli-to-ci" />

## Covers the protocol

MCP 2026-07-28 and earlier, over stdio, streamable HTTP and SSE: tools,
resources and templates, prompts, completion, progress, server logs, tasks,
subscriptions, elicitation, sampling, roots, and OAuth from client
credentials to enterprise managed authorization.
