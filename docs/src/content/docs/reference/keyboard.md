---
title: Keyboard Shortcuts
description: Every keyboard binding in MCP-TUI's terminal interface.
---

## Navigation

| Key | Action |
|-----|--------|
| `Tab` / `Shift+Tab` | Cycle tabs / focus rings |
| `↑` / `↓` | Move within a list |
| `←` / `→` | Move between columns |
| `Enter` | Select / activate |
| `Esc` | Cancel / close overlay |
| `b` / `Alt+←` | Back |
| `q` / `Ctrl+C` (twice) | Quit |

## Connection screen

| Key | Action |
|-----|--------|
| `C` | Toggle combined-command input |
| `Tab` | Switch between Saved / Discovery / Manual |

## Result panes

| Key | Action |
|-----|--------|
| `v` | View fields |
| `c` | Copy CLI command |
| `Ctrl+C` | Copy all output |
| `Ctrl+↑` / `Ctrl+↓` | Scroll line |
| `PgUp` / `PgDn` | Scroll page |
| `Home` / `End` | Top / bottom |

## Debug overlays

| Key | Action |
|-----|--------|
| `Ctrl+D` | Open debug screen |
| `Ctrl+L` | Open log viewer |
| `Tab` (in debug) | Cycle debug tabs |
