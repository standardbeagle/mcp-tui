# Risk Pipeline Rules

## 概 (Overview)

風險管道以五軸向量（`b d s r u`）評單元風險，路由適當審查層級。配置 YAML 在上方 frontmatter，運行時加載。任何鍵可項目覆寫；缺鍵回退插件默認。禁用管道置 `enabled: false`。

## 軸 (Axes)

五軸，各 0–3 整數：

- **b — blast** 爆炸半徑。LCI 2 層調用圖調用方計數經 log2 壓縮
- **d — data** 數據風險。持久化/外部數據破壞可能
- **s — security** 安全。認證、加密、授權、輸入驗證、秘密
- **r — reversibility** 不可逆性。已發布制品、破壞性操作
- **u — unknowns** 未知度。新模式、無測試覆蓋、生疏 API

## 級 (Level glyphs)

ASCII 字符，`emoji_glyphs: true` 則改 emoji：

| Glyph | Level | Meaning |
|-------|-------|---------|
| `.`   | 0     | 低 low      |
| `-`   | 1     | 中 med      |
| `+`   | 2     | 高 high     |
| `!`   | 3     | 危 critical |

## 預算 (Budget)

標量風險 = `Σ(weight_i × level_i)`，最大 `scalar_max × Σ weights`。默認 `scalar_max: 10` 對任一軸封頂，防單軸暴漲淹沒其他。`daily_tag_cap: 500` 限制每日 tagger 調用，超限降級至 pre-filter only。

權重表 `weights`：`security=4` 最重（安全零容忍）；`data=3` `reversibility=3` 次之；`blast=2` `unknowns=2` 最輕。

## 預過濾 (Pre-filter / trivial bypass)

八條件皆滿足方繞過 tagger 走極速管道：

1. 行增量 `< line_delta_trivial` （默認 20）
2. 增長比率 `< growth_ratio_max` （默認 1.2，防重寫偽裝）
3. 無 `security_paths_hardcoded` 命中（`auth/**` `crypto/**` `migrations/**`）
4. 無新導入外部依賴
5. 無 schema/migration 文件變動
6. 上下文行數 `< context_budget_lines` （默認 800）
7. 單元測試存在且通過
8. 歷史 tagger 未標 `s>=+` 或 `d>=+`

八條但凡一破即入完整管道。

## 升級 (Model escalation)

`model_routing.impl` 按標量映射至實現模型：

| Scalar | Model      |
|--------|------------|
| trivial | haiku-4.5 |
| 0–4     | haiku-4.5 |
| 5–9     | sonnet-4.6 |
| 10–14   | sonnet-4.6 |
| 15+     | opus-4.7  |

**臨界軸覆寫**：任一軸 `= 3` （`!`）無視標量，強制 `opus-4.7`。

**審查層**：
- `reviewer: one_tier_down` — 實現用 opus 則審查用 sonnet，sonnet 則 haiku
- `security_reviewer: same_as_impl` — 安全審查同實現模型（不降級）
- `post_task_reviewer: same_as_impl` — 任務後審查同級

**Tagger**：`default_model: haiku-4.5` 主標；`conf < conf_threshold` （0.7）或任軸 `= 3` 則升 `escalate_model: sonnet-4.6`。

## TDD 觸發 (TDD triggers)

任一條件中即強制 TDD（RED/GREEN/REFACTOR）：

- `d >= -` 數據風險 ≥ 中
- `s >= -` 安全風險 ≥ 中
- `b >= +` 爆炸半徑 ≥ 高
- `u >= +` 未知度 ≥ 高

全低（`. . . . .`）可豁 TDD，僅需冒煙測試。

## 遙測 (Telemetry)

`telemetry.path` （默認 `.risk-pipeline/telemetry.jsonl`）逐任務追加一行 JSON：


審計指標：false-skip rate、over-review rate。反饋調 `weights` `scalar_max`。

禁用遙測置 `telemetry.enabled: false`。

## 範例 (Examples)

**瑣事 trivial**：typo 修正，3 行改動，無依賴，無安全路徑。八預過濾皆過 → `. . . . .`，scalar=0，冒煙測試，haiku 實現。

**中危**：新 REST 端點，40 行，無 migration，觸測試。標量約 `b:- d:. s:- r:. u:-` = 1×2+0×3+1×4+0×3+1×2 = 8 → sonnet-4.6 實現，haiku 審查，TDD 觸發（`s>=-`）。

**臨界**：auth middleware 改寫，命中 `auth/**` 硬編碼路徑，新加密庫導入。預過濾破 3、4 條。標量 `b:+ d:- s:! r:- u:+` = 2×2+1×3+3×4+1×3+2×2 = 26 → opus-4.7 強制，security reviewer 同級，TDD 強制，post-task reviewer 同級。

## 覆寫指引 (Override guidance)

- **任意鍵可項目覆寫**。僅寫需改鍵，缺鍵繼承插件默認
- **完全禁用**：`enabled: false`，所有任務走默認管道（等同現狀）
- **臨時放寬**：調 `budget.daily_tag_cap` 或 `pre_filter.line_delta_trivial`；勿動 `weights` 除非團隊共識
- **加安全路徑**：擴 `pre_filter.security_paths_hardcoded`；模式為 glob
- **切模型**：`model_routing.impl` 替換模型名；確保已在組織白名單
- **schema_version** 僅插件升級時動；非向後兼容變更會提示手動遷移
